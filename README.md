# ASS → SUP Client Application

This repository now contains a product and technical specification for a desktop client that:

- Imports `.ass` subtitle files.
- Correctly renders ASS fonts, styling, effects, and movement.
- Converts the rendered output into a `.sup` (PGS) subtitle stream for export.

Start with the spec below for architecture, UI flows, and implementation details.
